# 只读管理工作台

用户端沿用 `/`，管理入口为 `/admin`。管理页复用现有账号 Cookie，每个数据接口单独验证权限，默认没有管理员。

## 启动

先在用户端注册并登录一个自己持有的账号，然后停止服务，在 PowerShell 中配置该账号的用户名（不是密码）：

```powershell
$env:SUPPORTPILOT_ADMIN_USERS = "你的已注册用户名"
python -m uvicorn supportpilot.api:app --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:8000/admin`。未登录时先回用户端登录；普通账号会被拒绝。多个管理员用英文逗号分隔，名单只通过服务端启动环境设置。已配置的管理员用户名不能通过注册接口抢注，因此必须先注册，再授权并重启。删除名单中的账号名并重启即可撤销管理权限。

## 当前能力

- 产品资料：固定语料清单、产品归属、官方来源、原文哈希版本、本地片段数量。
- 会话列表：问题标题、账号或访客、产品、结束状态，按创建顺序倒序分页。
- 逐轮轨迹：已提交轮次的反馈、状态、查询、检索正文、回复、校验与修正记录。
- 只读接口不改变用户端会话归属，管理员不能借用户端删除接口删除其他人的会话。

资料页不会初始化嵌入客户端或 Chroma，也不会自动调用模型。片段存在不代表向量入库已完成。未保存的失败尝试仍需查看本地日志。管理端尚未提供上传、版本发布或发起评测。

## 接口

| 接口 | 用途 |
| --- | --- |
| GET /admin/api/me | 当前管理员身份 |
| GET /admin/api/documents | 资料与本地片段概览 |
| GET /admin/api/sessions?limit=30&offset=0 | 会话分页，limit 最大 100 |
| GET /admin/api/sessions/{id} | 已保存轮次及最终 State |

原始轨迹属于私有数据，不应作为公开演示素材直接发布。此工作台服务于本机演示，公网部署需单独配置部署和权限策略。
